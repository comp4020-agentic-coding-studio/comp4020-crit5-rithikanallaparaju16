# Crit 5 reflection

**What was the breakthrough that moved the work forward?**

I started off by taking inspiration of one of my fav games "hill climb racing".
The game has an addictive yet simple music and very very easy to understand. So i
used that ideas but modified the terrain. My game takes place on the moon, so
gravity makes sense and even the character matches the same vibe

**What did this work change about who I want to be as a software developer?**

Simple game that can be understood by anyone is not as easy as it sounds. Every
user should think the same way and understand the game better as they go but
should not spend any time trying to understand how it starts. The trick is that
this game should also be tough to master, so the user has to understand the game
better

This has showed me that it is very tough to create things that are easy for the
user to understand but quite interesting to understand how the human brain works
to certain cues. I tried to make my character start at the left side of the
screen to show that the user needs to go forward and made the user understand
that they are on moon and slowly got in features of energy and all. This has made
me think like the user while I'm building itself.
